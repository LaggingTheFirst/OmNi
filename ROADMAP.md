# 🗺️ OmNi Roadmap

## ✅ Completed (Beta)
- Core file upload/download with live previews
- E2E encryption (client-side)
- User authentication & profiles (bio, display name, avatar)
- Privacy controls (public/private files & folders)
- Multi-language filename support (Unicode)
- Mobile-responsive PWA with QR connection
- Admin dashboard (logs, user management)
- Docker & standalone `.exe` deployment

---

## 🔜 Next Up (v1.0 Release)
- [x] **File Versioning**: Keep history of file changes, restore previous versions
- [ ] **Shared Folders**: Collaborative spaces for multiple users
- [ ] **Download Limits & Expiry**: Time-limited or download-count-limited share links
- [ ] **Trash/Recycle Bin**: Soft-delete with recovery window
- [ ] **Bulk Actions**: Multi-select for delete, move, download
- [ ] **User Groups & Permissions**: Group-based access control with granular permission levels *(Beta Tester Request)*

---

## 🚀 Future (v1.x+)
- [ ] **Comments & Annotations**: Discuss files directly in-app
- [ ] **Activity Feed**: Real-time notifications for uploads, shares, comments
- [ ] **File Search**: Full-text search across filenames and metadata
- [ ] **Guest Uploads**: Allow anonymous uploads to specific folders
- [ ] **Themes & Customization**: User-selectable UI themes
- [ ] **Plugin System**: Extend functionality with community add-ons

---

## 💡 Stretch Goals
- [ ] **WebDAV/SMB Integration**: Mount OmNi as a network drive
- [ ] **End-to-End Encrypted Messaging**: Secure DMs between users
- [ ] **Mobile Apps**: Native iOS/Android wrappers
