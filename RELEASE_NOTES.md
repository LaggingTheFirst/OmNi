# 🚀 OmNi Beta v1.0.0

The first public beta is here! OmNi brings modern design to local file sharing.

## ✨ New in this Release

*   **📱 Fully Mobile Responsive**: A stacked, touch-friendly interface that works perfectly on phones and tablets.
*   **🔒 Privacy Control**: Mark specific **folders** and files as Public or Private.
*   **🛡️ Global Admin**: Admins have full visibility over all folders and files to manage the server effectively.
*   **🐳 Docker Support**: Deploy instantly with the included `docker-compose.yml`.
*   **⚡ Faster Core**: Optimized CSS and refactored backend for better performance.

## 📥 How to Run

### Windows (No Install)
1.  Download `OmNi.exe`.
2.  Double-click to run.
3.  Access at `http://localhost:5000` or `http://<YOUR_IP>:5000`.

### Docker
```bash
docker-compose up -d
```

### Source
```bash
pip install -r requirements.txt
python run.py
```
